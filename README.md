# Girirajsinh Gohil — Portfolio

A responsive GitHub Pages portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in your browser.

## Publish at https://gvgohil232.github.io
1. Create a new **public** repository named `gvgohil232.github.io`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the GitHub Pages deployment to finish.

## Before publishing
- Confirm all project descriptions and employment dates are accurate and approved for public sharing.
- Replace the LinkedIn placeholder URL in `index.html` with your actual profile URL.
- Add your current PDF resume as `resume/resume.pdf` and add a download link if you want it available from the site.
- Add public demo/source links to each project only where they are safe and appropriate to share.

The portfolio intentionally does not invent public project repositories or demos. The project cards link to your public GitHub repositories list until individual repository links are confirmed.
